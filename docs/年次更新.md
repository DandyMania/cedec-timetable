# 翌年版への更新手順（例: CEDEC 2026 → 2027）

翌年の CEDEC 向けに、このビューアを更新するときの手順。
「更新して」と頼まれたら、まずこのファイルを読むこと。

> **鉄則**: 表示は絶対に間違えない。会場の階・タイムシフト日付などは
> **公式を見て再確認する。前年の値を推測で流用しない。**

---

## 0. 前提

- **公式が翌年の JSON を配布し始めてから**着手する。
  出るまで `scripts/fetch-data.mjs` は 404 になる。
  取得元は年で変数化済み（`officialUrl(y)` など、URL 自体の編集は不要）。

---

## 1. 機械的な置換（そのまま置き換えてOK）

| 場所 | 変更 |
|---|---|
| `app.js` の `CURRENT_YEAR` | `'2026'` → 新年（既定年・データパス・年ゲートの親玉） |
| `scripts/fetch-data.mjs` の `CURRENT_YEAR` | 同上 |
| `index.html` | `<title>`・description・見出し・`#CEDEC2026` の X 検索、公式リンク一式 `https://cedec.cesa.or.jp/2026/...`（timetable / map / access / awards / interactive / event）の年 |
| `manifest.webmanifest` | `name` / `description` の「2026」 |
| `sw.js` | `DATA_ASSETS` の `./data/2026/...` を新年へ。**あわせて `VERSION` を必ず上げる**（キャッシュ更新のため） |
| `.github/workflows/*.yml` | **`schedule:` ブロックを復活させる**（2026-08-01 に会期終了で削除済み）。復活後は cron コメントの日付も新年に揃える |

---

## 2. ⚠ 判断が要る＝公式を見て必ず再確認（推測で埋めない）

ここを前年のまま流用すると**間違った情報を表示する**。記憶に頼らず毎年確認する。

1. **会場 → 階の対応表（`app.js` の `ROOM_FLOOR`）**
   - パシフィコ横浜の会場割りは年で変わり得る。
   - 公式フロアマップ `https://cedec.cesa.or.jp/<年>/map/` を開き、
     「1F にどの第N会場、3F に…」を読み取って表を作り直す。
   - 2026 実績: 1F=第1〜3 / 3F=第4〜6・11〜13 / 4F=第7〜10（＝そのまま使わない、要再取得）。

2. **タイムシフト配信の締切（`app.js` の `TIMESHIFT_UNTIL` と `TIMESHIFT_DEADLINE_MS`）**
   - 公式が告知する「見逃し配信の視聴期限」を反映。
   - `TIMESHIFT_UNTIL` は表示用の文字列、`TIMESHIFT_DEADLINE_MS` は
     `Date.parse('YYYY-MM-DDThh:mm:00+09:00')` の機械比較用。両方直す。
   - 締切が不明・未告知なら、判明するまで暫定にしておき、判明後に更新。

3. **夜のイベント（`data/events.json`）**
   - 懇親会・Developers' Night などは手動キュレーション。
   - 前年分が残っていると去年のパーティが出る。翌年分に入れ替えるか、
     未確定なら空（`{"events": []}` 相当）にする。出典 URL も明記する。

---

## 3. データ生成

```
node scripts/fetch-data.mjs        # 公式 JSON を取り込み data/<新年>/ を生成し years.json に追記
node scripts/fetch-data.mjs --past # （必要なら）過去年アーカイブを再生成
```

- `data/<新年>/{sessions,meta}.json` と、統合された `data/years.json` が更新される。
- 会場番号は公式データに無いため、非公式ビューア（kazunori-toybox）から
  セッション id でマージしている（`fetch-data.mjs` 内）。マージ失敗時は前ビルドを流用する。

---

## 4. 動作確認（デプロイ前）

- 新年がデフォルトで開く／日付タブが新会期の日付になっている。
- タイムテーブルの会場名の横の階（1F/3F/4F 等）が**公式マップと一致**している。
- 配信ありの講演でタイムシフト注記・視聴/YouTube ボタンが出る。締切後は消える。
- 過去年（アーカイブ）が引き続き見られる。
- コンソールにエラーが無い。

---

## 5. タイムシフト仕様のメモ（自動で効くもの・確認だけ）

- タイムシフト対象の判定は feed の `note` 表記に依存（2 系統ある）:
  - 視聴ボタン（公式視聴ページ）: 「公式タイムシフト配信 NG」が**無ければ**対象
    （`hasOfficialTimeshift()`）。公式のタイムシフトは NG 指定以外の全講演をカバーする
    ことを 2026 年に detail ページで実地確認済み。
  - YouTube ボタン: 「YouTubeタイムシフト配信 OK」がある講演だけ（`hasYtTimeshift()`）。
  表記が同じなら自動で効く。表記が変わっていたら各関数の正規表現を直す。
- YouTube チャンネルは `@cedecyoutube5093` を想定（毎年同じか一応確認）。
  配信検索は「日付＋会場」で行うので年変更に強い。
- 会期が全日程過ぎると `eventOver()` が真になり、グレーアウト解除・視聴ボタンの
  タイムシフト限定表示に自動で切り替わる（コード変更不要）。
